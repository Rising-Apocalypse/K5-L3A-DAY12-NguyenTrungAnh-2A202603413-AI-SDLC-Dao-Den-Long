# AGENTS.md — Đảo Đèn Lồng (Lantern Island)

Small 3D game (TypeScript + Three.js) with a deterministic headless mode that is auto-graded against
`docs/spec/contract-v1.0.md`. Product context: `docs/spec/prd-0.md`. Plans: `docs/plans/`.

## Commands
- `npm ci && npm run build` — typecheck, `dist/headless.js`, `dist/web/`
- `npm test` — build headless + Vitest (unit, CLI, architecture guards)
- `npm run verify` — build + tests + every `tests/scenarios/*` run twice; writes `docs/proof/verify-latest.md`
- `node dist/headless.js --seed 1 --night 1|2|3 --ticks 600 --out out/a.jsonl [--scenario f.json] [--inputs f.json]`
- `npm run play` — serve the web build (Three.js view)

## Architecture rules (enforced by `tests/guards/architecture.test.ts`)
- `src/core/**` is pure TypeScript: no `three`, DOM, `fs`, no imports from `src/web`/`src/extras`/`src/headless`,
  and no `Math.random`/`Date`/`performance.now`. Randomness only via `src/core/rng.ts` (labelled streams).
- All gameplay goes through the single `step(input)` in `src/core/sim.ts`; web and headless share it.
- Every tuning number comes from `game.contract.json` via `src/core/tuning.ts`. No duplicated magic numbers.
- Per-night maps and rule flags live in `src/core/levels.ts` (`getLevel(night)`); Night 1 must stay byte-identical:
  `tests/guards/night1-golden.test.ts` compares 5 full runs with `tests/golden/*.jsonl` — never regenerate or edit `tests/golden`,
  fix the code instead (new behaviour goes behind a level flag that is off for Night 1).
- `src/extras/**` is web only and never loaded by headless (extras must not change headless output).

## Contract pitfalls
- Tick model: snapshot at tick 0 is before any input; step k reads input of tick k and emits events with
  `tick = k+1`; `--ticks N` is exactly N steps; `time_left_s = start - steps/60`.
- Buttons trigger on false -> true edges only; frames change only the fields they contain.
- Distances are on the XZ plane and "within r" means `<= r`.
- Building a scenario emits no events and awards no points.
- Malformed inputs/scenario file -> exit 2; bad CLI usage or unreadable file -> exit 1.
- Output must be byte-identical for the same seed + scenario + inputs. Coordinates are rounded to 3 decimals.
- Pause freezes everything (sim_tick, position, timers) but tick.
- Lantern fuel is stored as integer 1/60 units (full = 6000); the output `fuel` is rounded to 1 decimal. Never use floats for fuel.
- Snapshot key order is fixed (see `docs/plans/02-phase2-core-v1.1.md` §3.2).

## Definition of done
- `npm run verify` is green and `docs/proof/verify-latest.md` is regenerated by it.
- Never hand-edit `docs/proof/**` or anything in `out/`; they are generated.
- Never commit `.env` files or keys. Record every assumption in `docs/notes/assumptions.md`.
- Gameplay still to do is marked `// TODO(plan-01)` in `src/core/sim.ts`.
