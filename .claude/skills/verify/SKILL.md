# verify

1. Run `npm run verify` from the repo root. It builds, runs Vitest, then runs every `tests/scenarios/*`
   twice and compares the output bytes. It exits non-zero on the first failure.
2. Read `docs/proof/verify-latest.md` (generated; never edit it by hand). Check the commit/dirty line, the
   test counts and that every scenario row says `deterministic: yes` with an `end` line.
3. Nights 2-3: fixtures named `n2-*` / `n3-*` run with `--night 2|3`; `verify` also times
   `--night 3 --ticks 21600` (must be <= 30 s) and checks that Night 1 still matches `tests/golden/` byte for byte
   (`tests/guards/night1-golden.test.ts`). If that guard fails the Night 1 code path changed: fix the code, never regenerate `tests/golden`.
4. Only say "done" when step 1 exited 0 and the proof was regenerated by that run.

## Inspect a single scenario
```bash
npm run build:headless
node dist/headless.js --seed 1 --night 1 --ticks 600 \   # --night 2 / --night 3 for the other islands
  --scenario tests/scenarios/contract-sample/scenario.json \
  --inputs tests/scenarios/contract-sample/inputs.json --out out/one.jsonl
tail -1 out/one.jsonl                 # the mandatory end line
grep '"type":"event"' out/one.jsonl   # every event, in order
head -1 out/one.jsonl | node -e 'console.log(JSON.parse(require("fs").readFileSync(0,"utf8")).player)'
```
Exit codes: 0 ok, 1 bad usage / unreadable file, 2 malformed scenario or inputs JSON.
